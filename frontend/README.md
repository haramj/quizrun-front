# QUIZRUN — 퀴즈 월드

정답 하나, 앞으로 한 걸음. 친구들과 같은 문제를 풀며 달리는 라이브 퀴즈 MVP입니다.

## 퀴즈 월드 디자인

홈, 내 캐릭터, 방 만들기, 초대 코드 참가, 대기실, 퀴즈와 결과 화면을 작은 육상 경기장 콘셉트로 연결했습니다. 크림색 바탕과 잔디색, 빨간 육상 트랙, 연보라색 유니폼의 큰 얼굴 러너를 사용합니다. 시스템에 맞는 밝기와 수동 테마 전환을 지원합니다.

경기는 서버의 5초 카운트다운에 맞춰 준비 자세로 시작합니다. 출발 신호총과 연기, `탕! · 출발` 표시가 나온 뒤 팔과 다리를 움직이며 달립니다. 별도의 연출 시간을 추가하지 않으므로 설정한 문제 풀이 시간을 그대로 사용합니다. 정답 공개 때 서버 점수가 오른 러너는 1.2초간 스퍼트하며 총점에 비례해 전진합니다. 동작 줄이기 설정에서는 자세와 위치를 정적으로 표시합니다.

사진은 프로필의 큰 러너와 실제 경기의 원형 얼굴에 같은 자르기 결과로 표시됩니다. 참가자가 많을 때 얼굴이 작아지지 않도록 큰 화면은 6명, 휴대폰은 4명씩 트랙을 전환할 수 있고, `내 러너 보기`로 돌아올 수 있습니다. 순위표에는 모든 참가자가 표시됩니다.

방 만들기의 문제 수·제한 시간·최대 인원은 레이스 패스에 즉시 반영됩니다. `초대 코드로` 참가 방은 홈의 공개 목록에서 숨겨지며, 링크나 코드를 가진 사람은 참가할 수 있습니다. 이 옵션은 별도의 비밀번호 인증을 추가하지 않습니다.

## 실행

Node.js 20.12 이상. 외부 npm 의존성 없이 실행합니다.

```sh
npm start
# http://localhost:3000
npm test
```

`npm`이 없는 환경에서도 `node server.mjs`로 실행하고, `node --test test.mjs quiz-generator.test.mjs crop.test.mjs`로 테스트할 수 있습니다.

## 나만의 사진 러너

상단 내 캐릭터 또는 참가 전 프로필 화면에서 닉네임과 사진을 함께 설정합니다. JPG·PNG·WebP(최대 8MB)를 고르면 큰 원형 자르기 화면이 열립니다. 휴대폰 배경화면처럼 사진을 직접 드래그하고 두 손가락 확대/축소, 마우스 휠 또는 크기 막대로 0.5~5배까지 조절해 원하는 부분을 원 안에 맞추세요. 원 밖은 어둡게 표시됩니다. 1배 미만으로 축소하면 원 안에 사진 전체와 흰색 여백이 표시되고, 저장 결과에도 동일하게 반영됩니다.

`이대로 사용`을 누르면 자른 사진이 프로필과 실제 러너 미리보기에 반영됩니다. `취소`나 Escape는 이전 사진을 유지합니다. `사진 자르기`로 다시 조절하거나 `가운데 맞춤`으로 초기화할 수 있습니다. 자르기 화면에 포커스가 있을 때 방향키로 이동, +/-로 확대·축소, Enter로 적용할 수 있습니다. 마지막으로 `프로필 저장`을 눌러 저장하세요. `기본 얼굴로`는 사진을 제거합니다.

브라우저는 사진을 256×256 JPEG로 변환해 닉네임과 함께 로컬 저장소에 기억합니다. 방에 입장할 때 서버에 한 번 전달하고, 참가자 상태에는 사진 URL만 포함합니다. 사진이 100명분 매번 폴링되지 않도록 브라우저 캐시를 사용합니다. 경기 중 프로필을 바꿔도 현재 방을 유지하며 다른 참가자에게 반영됩니다. 캐릭터의 큰 얼굴과 순위표에 사진이 표시되고, 점수는 얼굴 아래에 배치됩니다.

사진은 참가자에게 보여 주는 공개 프로필 용도이며 브라우저와 실행 중인 서버 메모리에 저장됩니다. 방 정리 후 사용하지 않는 서버 사진도 정리합니다. 서버 재시작으로 방과 서버 사진은 초기화되지만, 같은 브라우저에 저장된 사진은 다음 입장 시 다시 전달됩니다.

## CLOVA Studio로 키워드 퀴즈 생성

NCP의 **CLOVA Studio API**를 사용합니다. CLOVA Chatbot의 시나리오 API와는 별개입니다. [공식 Structured Outputs 문서](https://api.ncloud-docs.com/docs/clovastudio-chatcompletionsv3-so)를 기준으로 `HCX-007`의 `/v3/chat-completions/HCX-007`을 호출합니다. API 키에 해당 모델의 사용 권한이 필요합니다.

1. 저장소 루트의 `.env.example`을 `.env`로 복사합니다. PowerShell에서는 `Copy-Item .env.example .env`를 사용하세요.
2. `.env`의 `CLOVA_STUDIO_API_KEY=` 뒤에 **CLOVA Studio API 키**를 입력합니다. NCP IAM Access Key/Secret이나 Chatbot Secret이 아닙니다.
3. `node server.mjs` 또는 `npm start`로 서버를 시작하거나 재시작합니다. Node가 `.env`를 자동으로 읽고, 이미 설정된 프로세스 환경 변수는 우선합니다.
4. 방 만들기에서 `AI 맞춤 출제`를 선택하고 `태양계`, `조선 시대 문화`처럼 자유로운 키워드(최대 60자)와 4·6·8·10·12문제를 지정합니다. 키가 있으면 AI 방식이 기본 선택됩니다.

기본 API 주소는 `https://clovastudio.stream.ntruss.com`입니다. 테스트 앱 호출 경로가 필요한 계정은 NCP 콘솔의 호출 예시를 확인해 `CLOVA_STUDIO_BASE_URL`을 `https://clovastudio.stream.ntruss.com/testapp`으로 설정할 수 있습니다. API 키는 브라우저로 전달하지 않으며 `.env`는 Git에서 제외합니다.

서버는 Structured Outputs로 4지선다 질문·정답 인덱스·해설을 생성하고, **요청한 문제 수**, 질문/보기 중복, 길이, 정답 범위를 검사합니다. 생성이 성공한 뒤에만 방을 만듭니다. 실패한 AI 요청을 문제은행 결과로 바꾸지 않으며 오류를 표시하고 다시 시도할 수 있습니다. 생성 대기 UI와 90초 제한, 최대 3건 동시 생성 제한을 둡니다. 동일 요청을 자동으로 재시도하지 않습니다.

정답과 해설은 서버에 보관하고 정답 공개 단계에서만 전송합니다. AI 문제 해설은 정답 공개 후 8초간 표시됩니다. 형식 검사는 사실의 정확성을 보증하지 않으므로 중요한 주제는 별도 검수가 필요합니다. 사진과 닉네임은 CLOVA 요청에 포함하지 않고 키워드와 문제 수만 출제 데이터로 보냅니다.

키가 없으면 문제은행 모드로 시작할 수 있습니다. AI를 선택하면 준비 중이라는 안내와 함께 생성 버튼이 비활성화됩니다. 설정 여부는 `/api/config`에서 공개하지만 키 값은 공개하지 않습니다.

자동 테스트는 실제 API 비용 없이 모의 CLOVA 서버로 요청/응답 규격, 문제 수, 실패 처리, 정답 비공개와 해설 공개를 확인합니다. **보유한 키로 실제 NCP 호출이 성공하는지는 키 설정 후 확인해야 합니다.** 공개 서비스에서는 인증과 사용자별 호출 한도를 별도로 추가하세요.

방을 만들고 초대 링크 또는 6자리 코드를 공유하세요. 다른 브라우저나 기기에서 입장하면 참가자가 즉시 표시됩니다. 정원이 차면 자동 시작하며, 방장은 혼자서도 시작할 수 있습니다. 문제당 기본 10초 (5·10·15·20·30초 선택), 정답 기본 1,000점 + 남은 시간 비율에 따른 최대 500점 보너스이며 동점은 공동 순위입니다. 서버가 정답, 마감, 중복 제출, 점수를 검증합니다.

## 다른 사용자 접속

서버는 `0.0.0.0:3000`에서 수신합니다. 같은 Wi-Fi에서는 `http://서버의-LAN-IP:3000`으로 접속할 수 있습니다. localhost 링크는 다른 기기에서 사용할 수 없으므로 LAN 주소로 접속한 뒤 초대 링크를 복사하세요. macOS 방화벽의 Node 연결 허용이 필요할 수 있습니다.

외부 인터넷 공개에는 NCP 서버와 도메인/HTTPS 설정이 필요합니다. 이 저장소를 서버에 배포하고 `npm start`를 실행한 뒤 리버스 프록시를 연결하세요. SSE 경로 `/api/rooms/:code/events`의 버퍼링을 끄고 연결 제한시간을 충분히 설정해야 합니다. 배포 계정 없이 공개 URL이 자동 생성되지는 않습니다.

## 구현 범위

- 반응형 퀴즈 월드 홈, 키워드 필터, 방 검색, 캐릭터 설정과 초대 코드 참가 화면
- 실제 참가자와 방 목록, 초대 링크, 6자리 코드
- 700ms HTTP 폴링으로 참가·문제·정답 공개·순위 동기화 (서버 SSE API도 유지)
- 정원 자동 출발 및 방장 수동 시작
- 서버 기준 선택형 타이머와 중복 답안 방지, 정답 사전 노출 방지
- 4/6/8/10/12문제 레이스와 결과 화면
- 브라우저 세션 내 재연결, 6시간 후 방 정리

키워드 출제는 **CLOVA Studio AI 생성**과 **문제은행** 중 선택합니다. 문제은행 모드에서는 상식·개발·과학·역사·스포츠·영화·음악·지리·음식·동물·언어·수학·미술·게임·환경 카테고리를 사용하고, AI 모드에서는 입력한 키워드를 그대로 주제로 사용합니다.

방 데이터는 프로세스 메모리에 있으므로 재시작 시 초기화됩니다. 퇴장한 참가자는 점수/재연결을 위해 자리를 유지합니다. 여러 서버 운영, Redis/MySQL, 사용자 인증, 부하 테스트는 미구현입니다. 10,000명 동시 접속 성능을 주장하지 않습니다. 공개 운영 전 접속/생성 제한과 영구 저장이 필요합니다.

## 구성

- `public/`: 순수 JavaScript / CSS 프론트엔드
- `public/world.js`, `public/world.css`: 미니어처 경기장, 사진 얼굴 러너, 달리기와 출발 연출, 전체 화면 스타일
- `public/profile.js`: 사진 자르기와 프로필 저장
- `server.mjs`: Node HTTP API / HTTP 폴링 / SSE 실시간 게임 서버
- `avatars.mjs`: 사진 입력 검증 및 콘텐츠 해시
- `quiz-generator.mjs`: CLOVA Studio 호출, 스키마/문제 수 검증, 보기 순서 섞기
- `questions.mjs`: 검증된 주제별 문제은행
- `test.mjs`, `quiz-generator.test.mjs`, `crop.test.mjs`: 게임·사진·AI 생성·사진 자르기·초대 방 테스트 (20개)

폰트는 Google Fonts를 사용하며 로드 실패 시 시스템 글꼴로 표시됩니다. NCP만 사용하는 배포라면 폰트를 자체 호스팅하거나 CSS의 `@import`를 제거하세요.

## 계정 없이 임시 공개 테스트

터미널 1에서 `npm start`, 터미널 2에서 아래 명령을 실행합니다.

```sh
cloudflared tunnel --url http://localhost:3000
```

출력되는 `https://...trycloudflare.com` 주소를 친구들에게 공유하면 휴대폰 LTE/5G에서도 접속할 수 있습니다. 별도 Railway/NCP 배포나 계정 없이 로컬 서버를 Cloudflare의 임시 HTTPS 터널로 연결하는 방식입니다. Quick Tunnel의 SSE 제한을 피하도록 브라우저는 인증된 상태 조회 API를 700ms 간격으로 호출합니다. 정답 채점과 마감 시간은 여전히 서버 기준입니다.

Mac, Node 서버, 터널이 계속 실행 중이어야 합니다. 터널 재실행 시 주소가 바뀌며 서버 재시작 시 방이 사라집니다. URL을 아는 사람은 접속하고 방을 만들 수 있습니다. 상시 운영 배포나 비공개 인증 서비스가 아닌 소규모 테스트용입니다.

## 스피드 점수와 채팅

정답 점수 = 1,000 + round(500 × 남은 시간 / 설정 시간). 서버가 답안을 받은 시각을 사용하며 오답·미제출은 0점입니다. 점수는 정답 공개 때 반영됩니다. 트랙 이동과 순위는 총점 기준이고 정답 수는 별도로 표시합니다. 네트워크 지연이 속도 보너스에 영향을 줄 수 있습니다.

방 참가자만 채팅을 읽고 쓸 수 있습니다. 메시지는 최대 200자, 최근 100개를 보관하며 700ms 내 연속 전송은 제한합니다. 메시지는 HTML을 이스케이프해 렌더링합니다. 대기·경기·결과 화면에서 사용할 수 있고, 상태 갱신 시 입력 중인 내용과 포커스를 유지합니다.

## 카테고리와 정원

15개 카테고리마다 12문제, 총 180문제를 제공합니다. 한 판은 4·6·8·10·12문제로 구성하고 문제 및 보기 순서를 무작위로 섞습니다. 한 판 안에서 문제 중복은 없으며 서로 다른 판 사이에는 같은 문제가 다시 나올 수 있습니다. 공개 카테고리 목록은 `public/topics.js`, 정답이 포함된 문제은행은 서버 전용 `questions.mjs`에 둡니다.

방 정원은 2~100명입니다. UI에서는 2·4·8·20·30·50·100명을 선택합니다. 100명 입장 및 정원 초과 차단을 자동 테스트했지만 100개 실제 브라우저의 동시 접속·폴링 부하 성능은 검증하지 않았습니다.
