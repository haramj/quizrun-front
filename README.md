# QUIZRUN ↗

정답 하나, 앞으로 한 걸음. 친구들과 같은 문제를 풀며 달리는 라이브 퀴즈 MVP입니다.

## 실행

Node.js 20 이상. 외부 npm 의존성 없이 실행합니다.

```sh
npm start
# http://localhost:3000
npm test
```

방을 만들고 초대 링크 또는 6자리 코드를 공유하세요. 다른 브라우저나 기기에서 입장하면 참가자가 즉시 표시됩니다. 정원이 차면 자동 시작하며, 방장은 혼자서도 시작할 수 있습니다. 문제당 15초, 정답당 1점/한 칸 이동이며 동점은 공동 순위입니다. 서버가 정답, 마감, 중복 제출, 점수를 검증합니다.

## 다른 사용자 접속

서버는 `0.0.0.0:3000`에서 수신합니다. 같은 Wi-Fi에서는 `http://서버의-LAN-IP:3000`으로 접속할 수 있습니다. localhost 링크는 다른 기기에서 사용할 수 없으므로 LAN 주소로 접속한 뒤 초대 링크를 복사하세요. macOS 방화벽의 Node 연결 허용이 필요할 수 있습니다.

외부 인터넷 공개에는 NCP 서버와 도메인/HTTPS 설정이 필요합니다. 이 저장소를 서버에 배포하고 `npm start`를 실행한 뒤 리버스 프록시를 연결하세요. SSE 경로 `/api/rooms/:code/events`의 버퍼링을 끄고 연결 제한시간을 충분히 설정해야 합니다. 배포 계정 없이 공개 URL이 자동 생성되지는 않습니다.

## 구현 범위

- 반응형 한국어 로비, 키워드 필터, 방 검색, 초대/닉네임 모달
- 실제 참가자와 방 목록, 초대 링크, 6자리 코드
- 700ms HTTP 폴링으로 참가·문제·정답 공개·순위 동기화 (서버 SSE API도 유지)
- 정원 자동 출발 및 방장 수동 시작
- 서버 기준 15초 타이머와 중복 답안 방지, 정답 사전 노출 방지
- 4/6/8문제 레이스와 결과 화면
- 브라우저 세션 내 재연결, 6시간 후 방 정리

현재 키워드 생성은 **상식·개발·과학·역사 문제은행**을 섞어 구성합니다. 임의 키워드 AI 생성 기능은 아직 연결되지 않았습니다. NCP CLOVA Studio 등 서버 측 생성 API와 검증 로직을 추가해야 합니다. UI에서도 문제은행임을 명시합니다.

방 데이터는 프로세스 메모리에 있으므로 재시작 시 초기화됩니다. 퇴장한 참가자는 점수/재연결을 위해 자리를 유지합니다. 여러 서버 운영, Redis/MySQL, 사용자 인증, 부하 테스트는 미구현입니다. 10,000명 동시 접속 성능을 주장하지 않습니다. 공개 운영 전 접속/생성 제한과 영구 저장이 필요합니다.

## 구성

- `public/`: 순수 JavaScript / CSS 프론트엔드 및 코드 기반 SVG 러너
- `server.mjs`: Node HTTP API / HTTP 폴링 / SSE 실시간 게임 서버
- `questions.mjs`: 검증된 주제별 문제은행
- `test.mjs`: 참가/자동·수동 시작/권한/중복 제출/비공개 정답 통합 테스트

폰트는 Google Fonts를 사용하며 로드 실패 시 시스템 글꼴로 표시됩니다. NCP만 사용하는 배포라면 폰트를 자체 호스팅하거나 CSS의 `@import`를 제거하세요.

## 계정 없이 임시 공개 테스트

터미널 1에서 `npm start`, 터미널 2에서 아래 명령을 실행합니다.

```sh
cloudflared tunnel --url http://localhost:3000
```

출력되는 `https://...trycloudflare.com` 주소를 친구들에게 공유하면 휴대폰 LTE/5G에서도 접속할 수 있습니다. 별도 Railway/NCP 배포나 계정 없이 로컬 서버를 Cloudflare의 임시 HTTPS 터널로 연결하는 방식입니다. Quick Tunnel의 SSE 제한을 피하도록 브라우저는 인증된 상태 조회 API를 700ms 간격으로 호출합니다. 정답 채점과 마감 시간은 여전히 서버 기준입니다.

Mac, Node 서버, 터널이 계속 실행 중이어야 합니다. 터널 재실행 시 주소가 바뀌며 서버 재시작 시 방이 사라집니다. URL을 아는 사람은 접속하고 방을 만들 수 있습니다. 상시 운영 배포나 비공개 인증 서비스가 아닌 소규모 테스트용입니다.
